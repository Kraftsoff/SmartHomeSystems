# Бэкапы `tz-site/` (Obsidian-vault)

Каждый архив — полный снимок `tz-site/` (ТЗ-документы `00`–`99` + `prototype/`) на дату в имени
файла. Полная история изменений всё равно живёт в git; эти архивы — на случай, если нужна
плоская папка без git, например для отправки клиенту или локального открытия в Obsidian.

**Как открыть бэкап в Obsidian:** распакуй архив в любую папку и открой её как vault
(File → Open folder as vault). Внутренние `[[wikilinks]]` между файлами `00`–`14`, `99`
рабочие — проверено на дату бэкапа (см. ниже).

## Архивы
- `tz-site-backup-2026-07-22.zip` — после завершения первого чернового прохода по всем 60
  статьям-рычагам (AEO) и стабилизации интерактивного дома (реальные ассеты день/ночь,
  инженерные системы, исправленная коллизия следов). Проверка целостности vault на эту дату:
  все `[[wikilinks]]` в `00 — MOC` резолвятся на существующие файлы, орфанных заметок нет.
- `tz-site-backup-2026-08-21.zip` — слепок на момент архивации: 101 маршрут, 73 рычага. Прототип с тех пор вырос, актуальное состояние снимается `node tools/accept.mjs`
  со своими страницами и поиском, сегменты, сравнения, цены, шоурум, юридический слой
  (152-ФЗ + ЗоЗПП + согласие на аналитику), 0 нарушений контраста и доступности.
  Предыдущие архивы удалены: история в git, дублировать снимки незачем.
