# 13 — Реальные дизайн-токены (извлечены из скомпилированного CSS)

← [[00 — MOC (карта ТЗ)]] · [[07 — Дизайн-система]]

> Источник: архив `mmsmart ru files.zip` — полные сохранённые страницы **с ассетами**
> (в т.ч. реальные `.css`-файлы Next.js, не только HTML). Это не Tailwind-классы «на глаз»,
> а точные значения из `2c5d780a13708402.css` (156 КБ) и `30cb2da45da6c9c7.css` (шрифты).
> **Это меняет предыдущие выводы** — записываю точно, включая то, что было ошибкой.

## ⚠️ Главная поправка: сайт СВЕТЛЫЙ, не тёмный
```css
body{background-color:var(--color-background); /* #f4f4f4 */
     color:var(--color-foreground);             /* #0b0d10 */
     font-family:var(--font-sans)}               /* Inter */
header{background:#F4F4F4/95} /* шапка тоже светлая, полупрозрачная при скролле */
```
Мой вывод в v2/v3 («база — тёмный #0a051a») был **неверным**: `#0a051a`/`#0b0d10` в реальном
CSS используются в основном как **цвет текста** (заголовки/лейблы: `text-[#0A051A]`), а не как
фон всей страницы. Частота упоминания в HTML вводила в заблуждение — это не то же самое, что
роль в дизайне.

## Полная палитра (переменные из :root)
| Токен | Значение | Роль |
|---|---|---|
| `--color-background` | `#f4f4f4` | Фон страницы |
| `--color-foreground` | `#0b0d10` | Основной текст |
| `--color-brand-blue` | **`#478beb`** | Основной интерактивный акцент — ссылки, «Узнать больше», hover |
| `--color-brand-gray` | `#5f6368` | Вторичный текст |
| `--color-brand-light-gray` | `#262626` | (несмотря на имя — тёмный, вероятно для конкретных тёмных блоков) |
| `#0a051a` / `#0b0d10` | near-black | Текст заголовков/лейблов (не фон!) |
| `#00d0ff` | циан | **Точечный декоративный акцент** (см. кнопку ниже), не системный токен |
| `#e27500` | оранжевый | Точечный акцент (ad hoc, не системный токен) |
| `#478beb`/`#4a5df9` | синие | Ссылки, ободки, декоративные formы |

**Вывод:** реальная иерархия цвета — **синий (#478beb) как основной интерактивный акцент**,
циан и оранжевый — второстепенные точечные акценты (бейджи, декоративные пятна), НЕ основная
дуотон-пара, как я предполагал раньше.

## Реальная кнопка (буквальный код, primary CTA «Связаться с нами»)
```html
<button class="group relative cursor-pointer bg-[#f8f9fa]
  shadow-[inset_-3px_-3px_6px_1px_rgba(255,255,255,0.5),inset_3px_3px_6px_0_#eaeaea,
          0_4px_6px_-2px_rgba(0,0,0,0.05),0_10px_15px_-3px_rgba(0,0,0,0.1)]
  rounded-[50px] flex px-8 py-3 border border-white
  items-center uppercase gap-1.5 font-semibold text-[13px]
  tracking-[-0.02em] text-[#00576b]
  transition-all duration-300 overflow-hidden">
  <!-- декоративные размытые «лепестки» по бокам, цвет rgb(196,249,252) (светлый циан), blur 6px -->
  <!-- + анимированный блик rgb(120,243,250) (циан), radial-gradient + blur(10px), движется по кнопке -->
  <span>Связаться с нами</span>
</button>
```
Это **неоморфизм** («мягкий UI»): светло-серый фон `#f8f9fa`, комбинация inset-теней (белый
блик сверху-слева + серая тень снизу-справа) + внешние мягкие тени — кнопка выглядит как
физическая мягкая панель/выключатель. Текст — **не белый на цветном фоне**, а тёмно-бирюзовый
`#00576b` на светлом. По бокам — декоративные размытые циановые «лепестки», плюс циановый блик,
который движется при взаимодействии (реальный, работающий приём — можно взять как техническое
решение для «живого» акцента, но в циане, не в оранжевом, как я делал).

## Типографика
- **Основной шрифт — Inter** (`--font-sans:var(--font-inter)`), самохостится, полный набор
  начертаний 100–900, применяется к `body` и, следовательно, **к заголовкам по умолчанию**
  (`h1-h6{font-size:inherit;font-weight:inherit}` — своих стилей нет, только `font-bold` утилита).
- **Helvetica — отдельный самохостящийся шрифт** (`@font-face{font-family:helvetica;src:url(helvetica_regular...)}`),
  подключается через утилиту `.font-helvetica` **точечно**: на навигации, лейблах, подписях,
  мелком тексте (100 вхождений в классах). **Не на всех заголовках.**
- Заголовки: `text-[40px] md:text-[52px] lg:text-[64px] font-bold tracking-[-0.01em] leading-tight`.
- **Правильная пара: Inter Bold — для заголовков, Helvetica — для нав/лейблов/мелкого текста.**
  (В v3 сейчас везде стоит Helvetica — это me a полуправда: надо разделить роли.)

## Радиусы, тени, тайминги
- Радиусы (Tailwind scale, переопределён slightly): `--radius-xs:2px`, `sm:4px`, `md:6px`,
  `lg:8px`, `xl:12px`; крупные карточки — `rounded-3xl` (24px, Tailwind-дефолт), кнопки — `rounded-full`
  или `rounded-[50px]`.
- Тени — **мягкие, низкоконтрастные чёрные**: `--shadow-sm:0 1px 3px 0 #0000001a,0 1px 2px -1px #0000001a`,
  `--shadow-md:0 4px 6px -1px #0000001a,0 2px 4px -2px #0000001a` (10% альфа). Никакого цветного
  «свечения» как основного приёма — только у декоративных акцентов (кнопка выше).
- Тайминги: `--default-transition-duration:.15s` (150мс!) на уровне системы; отдельные компоненты
  используют 300/400мс. Реальный сайт **быстрее и суше**, чем я закладывал.

## ⚠️ Стратегический вопрос (не техническая деталь — решение бизнеса)
Реальный текущий сайт — **светлый, неоморфный, «мягкий консьюмерский» дизайн** (пастельные тени,
округлые лепестки, дружелюбный тон). Это может не соответствовать новому позиционированию
«серьёзный инженерный подрядчик для премиальных объектов» (см. [[10 — ТЗ v2 (инженерный подрядчик)]]),
которое по духу ближе к строгому/тёмному/данные-ориентированному языку.

**Нужно решить:** брать светлый неоморфизм как основу нового сайта (макс. преемственность
бренда) — или использовать реальную палитру/шрифты как сырьё, но **сознательно уйти** от
мягкого консьюмерского тона к более серьёзному языку (тёмная база, строгая типографика),
как я делал в v2/v3. Это разные решения, я не должен молча выбирать за клиента в третий раз.

## ✅ Решение (2026-07-05): не выбираем — переключатель «День/Ночь» на самом сайте
Клиент выбрал показать оба варианта на прототипе → вместо статичного выбора реализован
**продуктовый тумблер День/Ночь** в шапке (`prototype/mimismart-v4.html`):
- **День** — светлый неоморфизм, токены буквально из реального CSS (см. выше): фон `#f4f4f4`,
  синий акцент `#478beb`, настоящая кнопка с мягкими тенями/циановыми «лепестками»/бликом.
- **Ночь** — тёмный инженерный (как в v2/v3): фон `#0a051a`, оранжевый/циан, дефолт по умолчанию
  (совпадает с позиционированием «инженерный подрядчик»).
- Переключение **не только тема — это демонстрация сценария объекта**: меняются показания на
  разрезе дома (свет `DALI · дневной свет` → `DALI · сцена 20%`, охрана `дома` → `усилен режим`,
  климат/вентиляция — дневные/ночные значения). Прямая демонстрация продукта: «дом ведёт себя
  по-разному днём и ночью», а не просто визуальный тумблер.
- Технически: `:root[data-mode="day"/"night"]` переопределяет CSS-токены + JS обновляет 4 текстовых
  узла телеметрии. Уважает `prefers-reduced-motion`.
