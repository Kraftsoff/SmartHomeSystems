# 07 — Дизайн-система

← [[00 — MOC (карта ТЗ)]]

> V1-каркас. Финальные токены зависят от выбранной [[08 — Концепции (A-B-C) на согласование]]
> и брендматериалов (⚠️ см. [[99 — Открытые вопросы и временные допущения]]).

## Принципы
- Премиальность через воздух, типографику и свет — а не через «украшательство».
- «Невидимая инженерия»: UI не спорит с контентом; главное — извлекаемый текст + фирменная анимация.
- Консистентность: одна система в светлой и тёмной теме.

## Токены — извлечены из реального HTML (2026-06-29, из Tailwind-классов сохранённых страниц)
Не черновик — это буквальные значения из работающего сайта (`_next` CSS-классы + inline utility):
- **Цвет:** база `#0a051a`, акцент бренда `#e27500` (класс `text-brand`/`bg-brand`, 156 вхождений на
  главной), вторичный «brand-blue» `#00d0ff`, серые `#a8a8a9`/`#acacac`/`#d8d8d8`. Светлая тема:
  `#f4f4f4`/`#efefef`/`#121212`.
- **Шрифты:** класс `font-helvetica` (100 вхождений) — заголовки и текст на **жирном Helvetica/
  гротеске**, НЕ serif. `font-bold`, `tracking-[-0.01em]` до `tracking-[-0.05em]` на крупных
  заголовках. Масштаб заголовков: `text-[40px] md:text-[52px] lg:text-[64px]` (H2), `text-[24-28px]` (H3).
- **Скругления:** `rounded-full` (кнопки/пилюли, 33 вхожд.), `rounded-3xl` = 24px (крупные карточки/
  изображения, 20 вхожд.), `rounded-[50px]`/`rounded-[20px]` (отдельные блоки), `rounded-xl` = 12px
  (мелкие элементы).
- **Анимация/тайминги:** только `transition-colors`/`transition-transform`/`transition-opacity`,
  `duration-300`/`duration-400`, `ease-in` — сдержанно, без сложных эффектов на самом сайте сегодня.
  Декоративные `blur-[20px]`/`blur-[8px]` за карточками — мягкое свечение уже используется как приём.
- **Сетка:** `gap-4` доминирует (41 вхожд.), затем `gap-2`/`gap-3`; отступы небольшие, компактные
  относительно широких hero-зон.

Применено в `prototype/mimismart-v3.html` (v3.1): заголовки переведены на Helvetica/гротеск,
радиус карточек — 24px, тайминги transition — 300мс.

## Компоненты (ядро)
- Header + мега-меню; footer-таксономия (взять из сильного текущего футера).
- Карточка функции (с мини-анимацией), карточка оборудования, карточка кейса, блок-рычаг
  (H1-вопрос → ответ → шаги → цена → почему мы → FAQ), сравнительная таблица, калькулятор,
  хлебные крошки, CTA-блок.
- Состояния: hover/при наведении дом реагирует; empty/loader/404 с «жителем».

## Инструменты дизайна
- **Google Stitch** (stitch.withgoogle.com) — по запросу клиента добавлен как референс/инструмент
  генерации UI-черновиков. Не MCP-сервис и недоступен из этого окружения (сеть закрыта на внешние
  домены) — подключить как коннектор нельзя. Рабочий режим: дизайнер генерирует макет в Stitch →
  экспортирует/скриншотит → присылает сюда → переводим в HTML/React в нашей дизайн-системе и стеке.
- **Figma MCP** — подключён и рабочий в этой сессии (`get_design_context`, `use_figma`,
  `download_assets` и др.). Если нужна генерация/синхронизация дизайна прямо из сессии — используем
  его вместо Stitch: он читает и пишет в реальные Figma-файлы без сетевых ограничений.
