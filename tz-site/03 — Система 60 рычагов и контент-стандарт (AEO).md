# 03 — Система 60 рычагов и контент-стандарт (AEO)

← [[00 — MOC (карта ТЗ)]] · по скиллам `ai-seo`, `copywriting`, `content-strategy`

## Что такое «рычаг»
Страница/блок вида: **реальный запрос → прямой ответ → как реализуется → для кого →
сколько и почему → почему мы → возражения/подводные камни**. Это единица цитируемости для ИИ
и единица убеждения для человека. Ядро ТЗ — **60 рычагов** (кластеры под query fan-out).

## Шаблон рычага (обязательная структура каждой страницы `/answers/{slug}`)
1. **H1 = вопрос** (как пишет пользователь/ИИ).
2. **Прямой ответ 40–60 слов** (machine-extractable, в первом абзаце). ← эталон уже есть на сайте: `/controller`.
3. **Как это делается** (по шагам, «как код») — `HowTo`.
4. **Для кого / в каких случаях** (привязка к персоне) — и когда НЕ нужно.
5. **Сколько и почему** — вилка цены, из чего складывается, **почему дешевле = риск**.
6. **Почему мы** — доказуемо (своё производство, с 2004, кейс с цифрами, локальная работа без облака).
7. **Возражения / подводные камни** — `FAQPage`.
8. **Доказательства** — статистика с датой/источником, цитата эксперта, кейс.
9. **CTA** — рассчитать / в шоурум.
10. **Разметка** — `FAQPage` + `HowTo` + `BreadcrumbList`, «обновлено: дата».

## Стандарт языка: humanizer + stop-slop (ОБЯЗАТЕЛЬНО)
Весь текст сайта проходит через скиллы `humanizer` (33 паттерна ИИ-письма по гайду Wikipedia)
и `stop-slop` (активный залог, конкретика, ритм). Практически:
- никаких «важную роль играет», «подчёркивает значимость», «-ing-довесков», филлеров;
- никаких пустых деклараций — вместо «риски значительны» пишем «штробление по чистовой»;
- обороты «не X, а Y» — только в позиционирующих формулах клиента, не как приём;
- ритм рваный: короткое предложение рядом с длинным; читатель в сцене («вы», объект, стадия);
- для русского тире — норма пунктуации, англ. правило «no em dashes» буквально не применяем;
- самопроверка по скорингу stop-slop (5 шкал × 10); ниже 35/50 — переписать.

## Стандарт контента (жёсткий — из [[00 — MOC (карта ТЗ)]] и `ai-seo`)
- Заголовок = вопрос. Первый абзац = ответ. Факт > прилагательное.
- Цитируемость по Princeton GEO: **источники (+40%)**, **статистика (+37%)**, **цитаты (+30%)**.
- Запрещено: вода, «как выбрать лучший…», keyword-stuffing (−10%), контент «только для ИИ».
- Свежесть: «обновлено: дата» на каждой странице.

## Индекс 60 рычагов (кластеры) — черновик
> Полный проработанный список ведём отдельным файлом при утверждении; здесь — карта кластеров.

- **A. Доверие/выбор (6):** как выбрать интегратора · лучшие в Москве · российский производитель ·
  DIY или интегратор · vs готовые экосистемы · отзывы/надёжность.
- **B. Цена/экономика (7):** сколько стоит (квартира/дом) · из чего складывается · почему дорого ·
  чем опасен дешёвый · цена за м² · окупаемость/энерго · поэтапно без потери качества.
- **C. Сегменты (7):** квартира · коттедж · офис · ЖК/застройщик · премиум · дача · коммерция с посетителями.
- **D. Подсистемы (10):** освещение · климат · безопасность · шторы · мультирум · домофон ·
  протечки · электропитание/энергоменеджмент · фасад/ландшафт/полив · сауна/бассейн/камин.
- **E. Технологии (7):** децентрализация · без облака/локально/приватность · свои контроллеры ·
  проводной vs беспроводной · протоколы/совместимость (KNX/Modbus/…) · отказоустойчивость · обновляемость.
- **F. Процесс (6):** этапы · сроки · проектирование · монтаж (новостройка vs готовая) · гарантия · сервис/поддержка.
- **G. Возражения (6):** vendor lock-in · «если закроетесь» · сложно ли пользоваться · ремонтопригодность ·
  расширяемость · кибербезопасность/взлом.
- **H. Сравнения (5):** vs KNX · vs Яндекс/Apple/Sber · vs китай/DIY · KNX по цене · комплект vs проект.
- **I. B2B/партнёры (3):** стать дилером · работа с оборудованием для интеграторов · застройщикам/ЖК.
- **J. Эксплуатация (3):** приложение · сценарии автоматизации · обучение/передача объекта.

Итого 6+7+7+10+7+6+6+5+3+3 = **60**.

## Первая волна — черновик в прототипе (6 из 60)
В `prototype/mimismart-v5.html` (страницы «Главная» и «Статьи») вместо карточек-заглушек —
первый черновой проход по 6 рычагам (карточка = прямой ответ 40–60 слов, без полной страницы
`/answers/{slug}` с HowTo/FAQPage — это будет на Этапе 2):
- Процесс → «Когда подключать умный дом при ремонте?»
- Цена → «Сколько стоит инженерия для квартиры 150 м²?» (цифра `от 2–3 млн ₽` помечена ⚠️,
  как и везде на сайте — не подтверждена)
- Технологии → «Проводной умный дом или облачные гаджеты?»
- Сегменты → «Умный дом для офиса: с чего начать?»
- Освещение → «DALI-освещение: когда оправдано?»
- Безопасность → «Что делать, если топят соседи?» (ссылается на сценарий «протечка» в демо-доме)
Остальные 54 — по мере утверждения фактов (см. [[99 — Открытые вопросы и временные допущения]]).
