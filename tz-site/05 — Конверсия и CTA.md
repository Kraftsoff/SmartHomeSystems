# 05 — Конверсия и CTA

← [[00 — MOC (карта ТЗ)]] · по скиллам `cro`, `offers`, `marketing-psychology`

## Иерархия действий
1. **Основное:** «Рассчитать стоимость» (калькулятор-лид-магнит) → заявка.
2. **Сильное офлайн:** «Записаться в шоурум» (уже хорошо подано на сайте — усилить).
3. **Мягкое:** консультация/обратный звонок; подписка на кейсы.

## Квалификация (в форме/калькуляторе)
Тип объекта (квартира/дом/офис/ЖК) · площадь м² · стадия (новостройка/готовый ремонт) ·
набор подсистем · бюджетный ориентир. → сразу маршрутизирует в нужную персона-ветку и
даёт ИИ/менеджеру контекст «кто ты».

## Психология (marketing-psychology)
- **Доверие вперёд цены:** пруфы (производство, 20+ лет, кейсы) до ценника.
- **Якорение цены + обоснование** «почему столько» и «почему дешевле = риск» (снимает возражение №1).
- **Снижение тревоги:** гарантия, сервис, «производитель с 2004», локальная работа без облака.
- **Социальное доказательство:** кейсы с цифрами, отзывы с источником, рейтинг с ссылкой.
- **Дефицит/конкретика без манипуляций:** реальные сроки, слоты шоурума.

## CTA-правила
- На каждой странице рычага — CTA «рассчитать» + ссылка на кейс/сравнение.
- CTA-кнопка — правый край header; повтор после ключевых блоков.
- Формы — минимум полей на входе, дозапрос в диалоге.

## Лид-магниты (offers)
- **Калькулятор стоимости** (главный — он же контент про цену для ИИ).
- Чек-лист «что заложить в проект до ремонта».
- PDF-гайд по сегменту (квартира/дом) — открытый (не гейтить полностью, чтобы читал ИИ).
