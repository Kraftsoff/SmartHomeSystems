# 09 — Совет экспертов (эмуляция `/council`)

← [[00 — MOC (карта ТЗ)]]

> Скилла `/council` в окружении нет, поэтому «совет» собран как мультиролевой разбор ТЗ и
> концепций ([[08 — Концепции (A-B-C) на согласование]]). Каждый — вердикт, риск, рекомендация.

## 🧭 Директор по маркетингу / бренд
- **За:** стратегия «источник для ИИ» верна; отстройка «полный цикл + локально без облака» — сильная.
- **Риск:** без реальных цен и кейсов любая концепция останется «красивой витриной».
- **Реко:** приоритет — цифры-пруфы и цены (разблокируют рычаги). Концепция **B×C**.

## 🏗️ Ведущий фронтенд-архитектор
- **За:** остаёмся на Next.js — меньше миграции.
- **Риск:** Концепция A/C на WebGL легко убивает LCP и SSR; «живой hero» должен быть
  прогрессивным улучшением, не блокирующим контент.
- **Реко:** **Rive** + строгий бюджет кадра, `prefers-reduced-motion`, статичный SSR-фолбэк. Санировать e-commerce-слой (нужен ли в V1).

## 🔎 SEO/AEO-лид
- **За:** система рычагов + кластеры = точное попадание в query fan-out.
- **Риск:** текущие дыры (нет meta/H1/schema/цен, опечатки-slug, непроверенный SSR) — блокеры цитируемости.
- **Реко:** P0 — мета-слой, schema, `/llms.txt`+`/pricing.md`, robots (YandexBot!), 301-редиректы. Концепция **B** технически идеальна.

## 🎨 UX / Motion-дизайнер
- **За:** «живое жилище» — сильный, уместный, продающий приём (интерактив = демонстрация продукта).
- **Риск:** анимация ради анимации утомляет и вредит доступности/мобиле.
- **Реко:** motion с смыслом (реакция на присутствие), обязательный reduced-motion и мобильная упрощённая версия. Гибрид с акцентным hero из **A**.

## 💼 Продажи / голос клиента
- **За:** квалификация в калькуляторе = тёплые лиды с контекстом «кто ты».
- **Риск:** возражение «дорого» не закрыто без блока «почему столько / почему дешевле = риск».
- **Реко:** цены с обоснованием + кейсы с цифрами на видном месте; **C** (персона-адаптив) ближе всего к реальной продаже.

## 📊 Владелец продукта / бизнес
- **За:** один сайт заменяет 5 легаси; управляемость и рост.
- **Риск:** объём (76 рычагов + кейсы + цены + анимация) — нужен этапный релиз, не «всё сразу».
- **Реко:** MVP-волна (P0 + 10–15 рычагов + герой), затем масштабирование. Гибрид **B×C**. <!--sync-ok-->

## Синтез и решение совета
- **Направление:** гибрид **B×C** + акцентный «живой hero» из **A** (см. рекомендацию в [[08 — Концепции (A-B-C) на согласование]]).
- **Порядок работ:**
  1. **P0 (фундамент):** мета-слой, schema, robots/sitemap/llms.txt/pricing.md, SSR-проверка, редиректы, реальные контакты.
  2. **Контент-ядро:** цены с обоснованием + 10–15 приоритетных рычагов + 5–10 кейсов.
  3. **Фирменный слой:** «живое жилище» (Rive) на hero + карточках, прогрессивно.
  4. **Масштаб:** до 76 рычагов + сравнения + персона-адаптив.
- **Главный блокер:** факты клиента (цены, пруфы, кейсы, контакты) — [[99 — Открытые вопросы и временные допущения]].

> При желании могу провести более «жёсткий» совет — реальными субагентами (по роли на агента,
> с адверсариальной проверкой). Скажи, если нужно.
