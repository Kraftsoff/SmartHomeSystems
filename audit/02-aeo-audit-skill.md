# AEO/AI-SEO аудит MiMiSmart — по скиллу `ai-seo` (coreyhaines31/marketingskills v2.1)

Аудит проведён по фреймворку скилла **ai-seo** (AEO/GEO): «Traditional SEO gets you ranked.
AI SEO gets you **cited**». Цель — чтобы ИИ (Google AI Overviews, ChatGPT, Perplexity, Gemini,
Copilot) **цитировал** MiMiSmart как источник. База: 5 собранных страниц + карта сайта.

> Где данных из снимка не хватает (robots.txt, schema в raw-HTML) — помечено «проверить».

**Эталон уже есть на сайте:** первый абзац `/controller` — «Это мозг системы. Они принимают
сигналы от датчиков и панелей, запускают сценарии и управляют светом, климатом, шторами и

answer-блок** (определение + дифференциатор «локально без интернета»). Его формат нужно
тиражировать на все страницы. Сейчас это исключение, а не правило.

## 2. Три столпа AEO (фреймворк скилла) → статус MiMiSmart

### Столп 1. Structure (извлекаемость) — 🔴 слабо
- Нет H1, нет заголовков-вопросов, нет FAQ, нет сравнительных таблиц, нет definition/howto-блоков
  (кроме `/controller`). ИИ извлекает пассажи, а не страницы — извлекать нечего.
- **Действие:** каждую страницу функции/сегмента перестроить по блокам скилла: Definition →
  How-to → Comparison → Pros/Cons → FAQ → Statistic-блок. Это ровно структура наших «78 рычагов».

### Столп 2. Authority (цитируемость) — 🔴 очень слабо
Princeton GEO (из скилла) — что реально поднимает цитируемость:

| Метод | Буст | Сейчас у MiMiSmart |
|---|:--:|---|
| Cite sources (ссылки на источники) | +40% | нет |
| Add statistics (цифры + источник + дата) | +37% | заявления без пруфов |
| Add quotations (эксперт + должность) | +30% | нет |
| Authoritative tone | +25% | частично |
| ~~Keyword stuffing~~ | **−10%** | риск в мета-шаблонах — избегать |

- У MiMiSmart есть **уникальные данные** под original-research контент (которому ИИ доверяет):
  «5000+ объектов», «с 2004», «своё производство контроллеров», «20 представительств»,
  децентрализация. Сейчас это лозунги без доказательств → нужно превратить в
  **статистику с источником/датой + экспертные цитаты инженеров + кейсы с цифрами**.
- E-E-A-T: нет авторов, дат, first-hand опыта на страницах. Контакты-заглушки
  (телефон с кодом Калининграда при московском адресе, почта на `mail.ru`) — прямой
  антидоверительный сигнал (см. `audit/01-marketing-audit.md`).

### Столп 3. Presence (быть там, где ищет ИИ) — 🟠 вне сайта, но критично
Скилл: «brands are 6.5x more likely to be cited via third-party sources than their own domains»;
Wikipedia ≈ 7.8% всех цитирований ChatGPT, Reddit ≈ 1.8%, плюс YouTube/обзоры/отзывы.
- **Действие:** актуальная страница в Wikipedia/Рувики, присутствие на отзовиках и в
  отраслевых подборках «лучшие интеграторы умного дома», YouTube по how-to и обзорам
  оборудования, экспертные ответы на профильных площадках. Для рынка РФ — добавить
  Яндекс-эквиваленты (Яндекс.Бизнес/карточки, отзовики Рунета).

## 3. Machine-readable файлы для ИИ-агентов (раздел скилла) — 🔴 отсутствуют

Скилл прямо предупреждает: «AI agents aren't just answering questions — they're becoming
buyers… opaque pricing gets filtered out of AI-mediated buying journeys». У MiMiSmart:
- ❌ **нет `/pricing.md`** — и при этом самой страницы цен тоже нет (двойной провал: и человек,
  и ИИ-агент не получают цену → агент порекомендует конкурента с читаемой ценой).
- ❌ **нет `/llms.txt`** (карта-контекст для LLM: кто мы, для кого, ключевые страницы).
- ❌ нет OKF-бандла (`/okf/`) — опционально, протокольный слой (Google, v0.1).
- **Действие (приоритет):** добавить `/llms.txt` + `/pricing.md` со структурой «сегмент →
  вилка цены → что входит → из чего складывается». Это и закрывает разрыв «нет цен», и делает
  MiMiSmart выбираемым для агентных покупательских сценариев.

## 4. Schema.org (раздел скилла) — 🔴 не обнаружено
Нужные типы под MiMiSmart: `Organization` + `LocalBusiness` (адрес/телефон/часы/гео — у нас
есть реальный адрес!), `Product`/`Offer` (оборудование + цена), `FAQPage` (под рычаги),
`HowTo` (как работает/как настроить сценарий), `Review`/`AggregateRating` (рейтинг 4.9 — с
источником!), `BreadcrumbList`. → реализовать через скилл **schema**.

## 5. AI-bot access (раздел скилла) — ❓ проверить
Убедиться, что `robots.txt` НЕ блокирует: `GPTBot`, `ChatGPT-User`, `PerplexityBot`,
`ClaudeBot`, `anthropic-ai`, `Google-Extended`, `Bingbot`, `YandexBot`. Блок = платформа
физически не может процитировать. Также проверить SSR (контент в raw-HTML до JS) — иначе
и ИИ-движки, и агенты видят пустую страницу.

## 6. Query fan-out (раздел скилла) — 🟢 потенциал высокий
Google под капотом веером генерит связанные запросы и синтезирует ответ по кластеру.
Вывод скилла: покрывать **весь топиковый кластер**, а не одну страницу под один ключ.
- У MiMiSmart **уже есть таксономия** (Шторы/Освещение/Климат/Мультимедиа/Безопасность/
  Электрика/Оборудование/Датчики/Решения) и сегменты (квартира/дом/офис/ЖК) — это готовый
  каркас под кластерное покрытие. **Система «78 рычагов» = реализация этого принципа.**

## 7. Типы контента, которые ИИ цитирует чаще (раздел скилла) → пробелы MiMiSmart

| Тип | Доля цитирований | Есть у MiMiSmart? |
|---|:--:|---|
| Сравнительные статьи (X vs Y) | ~33% | ❌ нет ни одной → **топ-возможность** |
| Подробные гайды | ~15% | ❌ (статьи — заглушки «Тестовое описание») |
| Original research / данные | ~12% | ❌ (есть сырьё: 5000+ объектов, своё произв.) |
| Best-of / листиклы | ~10% | ❌ |
| Карточки товара | ~10% | ⚠️ 1 товар (CUARM5M), без характеристик/цены |
| How-to гайды | ~8% | ⚠️ есть зачатки (сценарии «утро/протечка») |

**Вывод:** самый недоиспользованный и самый цитируемый формат — **сравнения**
(vs KNX, vs Яндекс/Apple/Sber экосистемы, vs дешёвый интегратор, vs DIY). Их нет вообще.

## 8. What NOT to do (из скилла) — на что не свалиться при доработке
- Не писать «отдельный контент для ИИ» и не дробить страницы на ИИ-фрагменты (риск spam-политики).
- Не keyword-stuffing (−10% к ИИ-видимости).
- Не прятать контент за JS, который не рендерится (теряем и ИИ-движки, и агентов).
- Не блокировать ИИ-ботов, если хотим цитирования.
- Не «мы лучшие» без данных — цитируется «наши клиенты получают Х», а не «высокое качество».

## Приоритетный план (через призму ai-seo)

**P0 — фундамент извлекаемости и доверия:**
1. H1 + заголовки-вопросы + answer-блоки 40–60 слов на каждой странице (эталон — `/controller`).
2. Мета-слой (title/description/OG/canonical) — шаблонизировать.
3. Реальные контакты + `Organization`/`LocalBusiness` schema (адрес у нас реальный).
4. `/llms.txt` + `/pricing.md`; создать саму страницу цен с обоснованием.
5. Проверить robots.txt (ИИ-боты + YandexBot) и SSR.

**P1 — авторитетность (Princeton GEO):**
6. Превратить лозунги в статистику с источником/датой; добавить экспертные цитаты; кейсы с цифрами.
7. FAQPage + HowTo schema; даты «обновлено».

**P2 — цитируемые форматы и кластер:**
8. Сравнительные страницы (vs KNX / экосистемы / DIY) — формат №1 по цитируемости.
9. Развернуть **78 рычагов** поверх таксономии (покрытие query fan-out, definition/how-to/FAQ-блоки).
10. Presence вне сайта: Wikipedia/Рувики, отзовики, YouTube, отраслевые подборки.
