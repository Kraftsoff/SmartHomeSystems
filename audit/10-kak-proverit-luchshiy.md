# 10 — «Лучший сайт по умным домам в России»: как это проверить

Дата: 2026-08-21 · Статус: **рамка готова, часть измерений требует доступа из РФ**

## Зачем этот файл

Цель проекта сформулирована как «лучший сайт по умным домам со всех точек зрения в России».
В таком виде утверждение непроверяемо, а непроверяемые превосходства мы с сайта снимаем —
это правило `CLAUDE.md` и ст. 14.2 ФЗ-135. Значит, цель нужно перевести в измеримое.

Ниже — шесть измерений, по каждому: чем меряется, что у нас сейчас, и что нужно, чтобы
сравниться с конкурентами. Там, где замер сделан, стоит число. Там, где нет, сказано прямо.

## 1. Видимость в ИИ-ответах — главная по стратегии

| | |
|---|---|
| Чем меряется | доля цитирований в ответах Яндекс Нейро и Google SGE по 75 целевым запросам |
| Инструмент | Яндекс.Вебмастер, раздел «Видимость сайта в Алисе AI» — единственный прямой измеритель, бесплатный |
| У нас сейчас | **не измерено.** Сайт не запущен, домен не выбран |
| Что нужно | запуск, регистрация в Вебмастере, два-три месяца накопления |
| Ориентир | ни один интегратор нашего класса не встречается ни в одном из 75 запросов (`08`). Первое измеримое достижение — попасть в ответ хотя бы по одному |

## 2. Позиция в поиске по РФ

| | |
|---|---|
| Чем меряется | топ-10 Яндекса по 75 запросам, регион Москва, инкогнито |
| Инструмент | протокол в `09-serp-protocol-rf.md`, все запросы готовы |
| У нас сейчас | **замер только по американскому индексу.** Он даёт систематический перекос: «гарантия на умный дом» уезжает в ДДУ, «слаботочка» принимается за название ЖК |
| Что нужно | российский IP. Из рабочего окружения недостижим: шлюз режет и HTTP, и CONNECT |
| Что уже известно | старый сайт ранжируется по девяти запросам из 75 — это база, ниже которой опускаться нельзя |

## 3. Глубина и честность ответа — здесь мы можем сравниться уже сейчас

| | Мы | Что видно у конкурентов по замеру |
|---|---|---|
| Ответов с собственной страницей | 75 | тематические разделы без разбивки на вопросы |
| Развёрнутая часть | 83 400 знаков, 77 таблиц, медиана блока 1037 знаков | у большинства — общие слова без цифр и порогов |
| Прямой ответ первым абзацем | 75 из 75 | в выдаче начало абзаца чаще отвечает не на заданный вопрос |
| Неверных тезисов выдачи разобрано | 22 из 22 | — |
| Признание границ | «собственный контроллер — это и есть привязка к производителю», «камин в модели не показан» | не встретилось ни разу |

Это единственное измерение, где сравнение доступно без доступа к РФ-индексу: оно про содержание,
а не про позицию. Замер конкурентов сделан по заголовкам и сводкам, страницы не открывались.

## 4. Техническое качество

| Показатель | У нас | Норма |
|---|---|---|
| Битых маршрутов | 0 из 133 | 0 |
| Уникальных `title`/`description`/`canonical` | 133 из 133 | все |
| Нарушений контраста WCAG AA | 0 в обеих темах | 0 |
| Нарушений доступности по набору правил | 0 | 0 |
| Горизонтальная прокрутка на 360px, 200%, 400% | нет | нет |
| CLS | 0 | ниже 0.1 |
| Разметка сходится с DOM с JS и без | да | да |

Сравнить с конкурентами нельзя: для этого нужно открывать их страницы, а постраничная загрузка
из окружения заблокирована. Утверждать, что мы здесь лучше, оснований нет — есть основание
утверждать, что нарушений у нас ноль.

## 6. Внешние сигналы — наш самый слабый пункт

По доказательной базе (`05-aeo-evidence-2026.md`) на цитируемость в ИИ-ответах внешние сигналы
влияют сильнее внутренних: упоминания на YouTube, брендовые упоминания в вебе, отзывы на
Яндекс.Картах. **У нас здесь ноль**, и это не чинится качеством сайта. Единственный крючок на
самой площадке — `sameAs` в разметке `Organization`, и он пока пуст (`16`, C13).

## Честный вывод на сегодня

**Утверждать «лучший в России» нельзя ни по одному из шести измерений.** По четырём мы не
измерены относительно конкурентов, по двум измерены и там мы позади: внешних сигналов нет вовсе,
позиции в РФ-поиске не проверены.

**Что можно утверждать, потому что измерено:** нарушений технического качества, доступности и
контраста ноль; все 22 неверных тезиса выдачи разобраны; интегратор нашего класса не встречается
ни в одном из 75 запросов, то есть занятой позиции нет ни у кого.

Разница между этими двумя абзацами и есть то, что отделяет проверяемое утверждение от рекламного.
Первым мы пользоваться не будем, вторым — можем, с указанием, когда и чем измерено.

## Что закроет вопрос

1. Запуск и три месяца в Вебмастере — измерение 1.
2. Замер по протоколу `09` из РФ — измерение 2.
3. Профили компании для `sameAs` и внешняя активность — измерение 6.

До этого фраза «лучший сайт по умным домам в России» остаётся целью, а не характеристикой,
и на сайте её быть не может.
