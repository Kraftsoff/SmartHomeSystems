## 📊 Obsidian: визуал проектов

Репозиторий подготовлен как **Obsidian-vault** с визуальной доской проектов.

### Как открыть
1. Установите [Obsidian](https://obsidian.md).
2. `Open folder as vault` → выберите папку этого репозитория.
3. Откройте файл **`Projects Portfolio.canvas`** — это главная визуальная доска.

### Структура
```
Projects Portfolio.canvas   ← главная Canvas-доска (визуал)
Projects/                   ← заметки по каждому проекту
├── Сайт Сова.md
├── MiMiSmart Control Centre.md
├── NotaOS.md
├── Airsoft marketplace.md
├── Windows PDF Editor.md
└── Остров Мираж.md
```

### Категории на доске
- 🌐 **Web & Marketplace** — Сайт Сова, Airsoft marketplace
- ⚙️ **Системы & OS** — MiMiSmart Control Centre, NotaOS
- 🕹️ **Приложения & Игры** — Windows PDF Editor, Остров Мираж

Карточки на Canvas — это встроенные заметки: кликните, чтобы открыть и редактировать. Также работает **Graph View** благодаря `[[ссылкам]]` между заметками.
