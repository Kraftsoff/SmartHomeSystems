# PDF Studio

Удобный и комфортный **PDF-редактор для Windows**.

> Самостоятельный проект. Не связан с Совой, Мимисмарт и notaOS.

PDF Studio — настольное приложение для просмотра и редактирования PDF-документов
с комфортным интерфейсом: миниатюры страниц, аннотации, операции со страницами,
поиск и сохранение.

## Возможности

- **Просмотр и навигация** — открытие PDF, листание, масштабирование (100% /
  по ширине / по странице), миниатюры страниц, поиск по тексту, недавние файлы.
- **Аннотации** — выделение, подчёркивание, зачёркивание, рисование от руки,
  текстовые заметки, прямоугольники, линии и стрелки; выбор цвета.
- **Подпись и штампы** — подпись рисованием на холсте или загрузкой изображения;
  пресеты штампов (APPROVED, CONFIDENTIAL, DRAFT, дата и др.).
- **Забелка и редакция** — закрытие содержимого белым; настоящая редакция с
  безвозвратным удалением (страница растрируется при сохранении).
- **Операции со страницами** — поворот, удаление, дублирование, перестановка
  перетаскиванием миниатюр, вставка другого PDF, извлечение страницы/диапазона.
- **Формы** — чтение и заполнение интерактивных AcroForm-полей.
- **Экспорт и печать** — страница/диапазон в PDF, страница/все страницы в PNG,
  печать через системный диалог.
- **Отмена/повтор** — полноценная история изменений (Ctrl+Z / Ctrl+Shift+Z).
- **Сохранение** — запись изменений в PDF (Ctrl+S) или «Сохранить как…».
- **Темы и UX** — тёмная/светлая тема, горячие клавиши, свойства документа,
  drag & drop открытия файла.

## Технологии

| Слой            | Технология                          |
| --------------- | ----------------------------------- |
| Оболочка        | [Electron](https://www.electronjs.org/) |
| UI              | React + TypeScript                  |
| Сборка          | [electron-vite](https://electron-vite.org/) + Vite |
| Рендеринг PDF   | [pdf.js](https://mozilla.github.io/pdf.js/) (`pdfjs-dist`) |
| Редактирование  | [pdf-lib](https://pdf-lib.js.org/)  |
| Упаковка        | [electron-builder](https://www.electron.build/) (NSIS + portable) |

## Архитектура

```
src/
  shared/        Общий IPC-контракт (каналы и типы) для main и renderer
  main/          Главный процесс Electron: окно, меню, диалоги, файловый ввод/вывод
  preload/       Безопасный мост (contextBridge) с типизированным API
  renderer/      React-приложение
    src/
      lib/         pdf.js (рендер), pdf-lib (правки), аннотации, redact (растровая редакция), forms
      hooks/       useDocument (история), usePdfDoc (загрузка), useZoom, useTheme
      components/  Toolbar, ToolOptionsBar, Sidebar, PdfCanvas, AnnotationLayer, FindBar,
                   FormPanel, SignatureModal, ExportModal, InfoModal, StatusBar, Welcome
```

**Поток данных.** Главный процесс читает/пишет файлы и управляет нативным меню.
Renderer хранит документ как стек неизменяемых снимков (`bytes` + аннотации) —
это даёт простой и надёжный undo/redo. Структурные изменения (поворот,
удаление, перестановка) применяются через `pdf-lib` и порождают новые `bytes`.
Аннотации хранятся отдельным наложением в нормализованных координатах (0..1) и
«впекаются» в PDF при сохранении.

## Запуск (разработка)

```bash
npm install
npm run dev
```

## Сборка под Windows

```bash
npm run build:win
```

Артефакты появятся в `dist/`:

- `pdf-studio-<версия>-setup.exe` — установщик (NSIS);
- `pdf-studio-<версия>-portable.exe` — портативная версия.

> Примечание: сборка Windows-инсталлятора (`electron-builder --win`) выполняется
> на Windows либо в окружении с настроенным Wine. Типизация и сборка кода
> (`npm run build`) кроссплатформенны.

## Проверка кода

```bash
npm run typecheck   # проверка типов TypeScript (main + renderer)
npm run build       # типизация + сборка electron-vite
```
