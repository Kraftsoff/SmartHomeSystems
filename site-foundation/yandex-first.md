# Yandex-first: требования к коду и конверсии (РФ-рынок)

> Обязательный слой Этапа 1. Цель: топ Яндекса по целевым запросам + максимальная
> отдача от Яндекс.Директа + конверсия в заявку на РФ-аудитории.

## 1. Технический код (чтобы Яндекс любил)
- **SSR обязателен** — YandexBot хуже Google исполняет JS; весь контент и мета — в raw HTML.
- **Скорость**: LCP < 2.5s на мобильном 4G; вес первой загрузки < 1.5 МБ; шрифты — preload,
  анимации — после контента. Директ повышает цену за медленные посадочные.
- **Микроразметка Schema.org** (JSON-LD): Organization, LocalBusiness (адрес/часы/гео/телефон),
  Service, Product/Offer (цены!), FAQPage, BreadcrumbList — Яндекс показывает расширенные сниппеты.
- **Мобильная версия** безупречна: формы в один столбец, телефон кликабелен (tel:), кнопка
  мессенджеров (WhatsApp/Telegram) в зоне большого пальца.
- **turbo-страницы**: НЕ используем (устарели), вместо этого — быстрые обычные страницы.
- Кириллические URL не используем; slug латиницей; canonical на каждой странице.
- **hreflang не нужен** (пока RU-only), lang="ru".

## 2. Яндекс-инфраструктура (Этап 1)
- **Яндекс.Метрика** с вебвизором и картой кликов; цели: отправка формы (по типам),
  клик tel:, клик мессенджер, скачивание материалов, отправка проекта, запись в шоурум.
- **Яндекс.Вебмастер**: подтверждение, sitemap, мониторинг ИКС и запросов.
- **Яндекс.Бизнес + Карты**: карточка компании (шоурум!), рейтинг с отзывами — источник
  для «4.9» на сайте (сейчас цифра без источника ⚠️). Отзывы на Картах = конверсия из брендовых запросов.
- **Связка Метрика ↔ CRM** (офлайн-конверсии): передаём в Метрику статусы «SMART-лид/встреча/КП/оплата» —
  Директ обучается на качественных лидах, не на мусорных заявках.

## 3. Директ-готовность посадочных
- **Message match**: H1 посадочной = смыслу объявления. Для этого — отдельные посадочные
  под кластеры кампаний: `/functions/automation`, `/functions/climate`, `/pricing`,
  `/solutions/*`, плюс 78 страниц ответов под конкретные вопросы.
  ⚠️ Файла `meta-map.md`, на который ссылалась эта строка, в проекте нет — мета собирается
  в самом прототипе и проверяется `tools/accept.mjs`.
- **UTM-дисциплина**: все формы пишут utm_source/medium/campaign/term/content + referrer в CRM.
- **Подмена контента** (этап 2+): заголовок/оффер по utm_term (например, «умный дом в квартиру 120 м²»).
- **Быстрые ссылки** объявлений ведут на якоря: #price, #cases, #process — они должны существовать.
- **Форма выше фолда** на посадочных Директа + телефон в шапке всегда виден.
- **Квиз-форма** (наша квалификационная) как посадочная для холодного трафика: конверсия
  выше классической формы, и сразу отсекает нецелевых (площадь/бюджет/стадия).

## 4. РФ-специфика конверсии
- **ФЗ-152**: чекбокс согласия на обработку ПДн у каждой формы + страница политики;
  данные — на серверах в РФ (хостинг/CRM учесть при выборе. Vercel — проверить юр. допустимость ⚠️).
- **Мессенджеры**: Telegram/WhatsApp кнопки заметнее email (email в РФ конвертит слабо).
- **Обратный звонок** с выбором времени; часы работы по МСК на видном месте.
- **Доверие по-русски**: реквизиты юрлица (ИНН/ОГРН) в футере ⚠️, реальные фото производства
  и шоурума, сертификаты, договор на сайте — B2B-аудитория проверяет.
- Оплата/этапность: «работаем по договору, этапами» — прописать ⚠️.

## 5. Семантика под Директ/SEO (ядро кампаний)
Кластеры из ТЗ §11 (умный дом под ключ, проводной умный дом, инженерные системы для дома,
вентиляция для квартиры, DALI, мультирум, молниезащита...) + коммерческие модификаторы:
«цена», «стоимость», «под ключ», «Москва», «премиум». Каждому кластеру — посадочная из meta-map.
Минус-слова сразу: «своими руками», «дешево», «xiaomi», «алиса», «набор», «комплект купить».

## 6. Контроль качества (CI)
- Линт мета-слоя: у каждой страницы title ≤ 60 зн., description 120–160 зн., один H1.
  **Проверяется автоматически** — `tools/accept.mjs`, падает при нарушении.
  **Исключение — страницы ответов `/answers/{slug}`:** там заголовок и есть вопрос
  пользователя. Укоротить его до шестидесяти знаков значит потерять совпадение с запросом,
  ради которого страница существует. Выдача обрежет показ, но соответствие останется.
  Сейчас таких страниц 29 из 133; на остальных правило выполняется.
- Бренд в title добавляется, только если помещается в 60 знаков: подпись занимает 12,
  а смысл страницы важнее подписи.
- Lighthouse CI: perf ≥ 90 mobile на ключевых посадочных.
- Валидация JSON-LD (Schema.org validator + Яндекс валидатор микроразметки).
