# ВАЖНО о структуре файла: бот исполняет ТОЛЬКО ту группу, которая адресована ему.
# Правила из «User-agent: *» при этом не наследуются, а заменяются целиком. Поэтому
# служебные Disallow повторены в каждой группе — иначе персональное разрешение
# открывает боту /admin, закрытый для всех остальных.
#
# Почему здесь НЕТ /favorites, /search, /settings, /vendors. Эти легаси-разделы решено
# отдавать 410 Gone (redirects.md, раздел 10). Запрет обхода и удаление из индекса —
# противоположные вещи: бот, которому путь запрещён, никогда его не запросит, значит
# не увидит 410, и адрес останется в индексе записью без содержимого. Чтобы страница
# исчезла из выдачи, её нужно РАЗРЕШИТЬ обходить и отдать по ней 410.
# Закрывать обратно — только после того, как адреса выпадут из индекса.
