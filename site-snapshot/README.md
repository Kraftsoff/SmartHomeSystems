# site-snapshot — слепок текущего превью MiMiSmart

Источник: https://mimi-ibrh.vercel.app (превью нового сайта).
Способ сбора: пользователь сохранил HTML страниц из браузера (залогинен как admin) и
передал в сессию; распарсено скриптом `tools/` → текст/заголовки/ссылки/мета.

> Прямой автоматический доступ к сайту из рабочего окружения закрыт сетевой политикой,
> поэтому это снимок «как сохранил браузер», а не живой краулинг. Для проверки того,
> что отдаётся поисковым/ИИ-краулерам (raw HTML до JS), нужен `view-source`/curl снаружи.

Каждый `.txt`: TITLE / META / заголовки H1–H3 / ссылки / видимый текст.
`_index.json` — сводка. `SITEMAP.md` — полная карта маршрутов. `AUDIT-FINDINGS.md` — находки.
