# tradebot — торговая система: три вкладки + анализ мировых событий

Автономный бот с тремя вкладками **Акции · Ценные бумаги · Криптовалюта** и модулем
**События и идеи**, который собирает новости со всего мира (GDELT, RSS, NewsAPI, любой ваш
JSON-источник), пропускает их через аналитика на Claude и превращает в конкретные сделки:
«танкер арестован → нефть вверх → купить USO/BNO на 10 % капитала вкладки, стоп 2 ATR,
горизонт 72 часа». Брокеры: Alpaca (США, акции и ETF, paper-счёт), Т-Инвестиции (MOEX,
песочница), 100+ криптобирж через [ccxt](https://github.com/ccxt/ccxt).

Торгует по правилам, которые сначала проверяются на истории, потом на виртуальных деньгах
с живыми ценами и только потом на реальных. Управление с телефона и компьютера: веб-панель
и Telegram.

| 6 | Ссылка и формат вашего «инструмента событий» | вы называли инструмент, который вышел в прошлом месяце — пришлите название или URL его API | подключу как источник (`TB_INTEL_CUSTOM_URL` или POST `/api/intel/ingest`) |

Акции с 50 $ через Alpaca реальны (дробные акции без комиссий), но шорт на акциях требует
маржинальный счёт от 2 000 $. Поэтому медвежьи идеи по умолчанию выражаются **обратными ETF**
(SH, SQQQ, SCO, TBT), без маржи и без права на шорт.

## Сначала правда, потом код

1. **Гарантированного дохода не бывает.** Любой, кто обещает «пассивный доход на бирже
   без риска», либо продаёт курс, либо врёт. Большинство розничных алго-ботов теряют деньги.
   Этот бот не исключение по умолчанию: он даёт дисциплину и защиту капитала, а не чудо.
2. **50 $ — это бюджет на обучение, а не на доход.** Биржевая комиссия 0.1 % за сторону
   и минимальный ордер 5–10 $ означают, что при частой торговле мелкий счёт съедают издержки.
   Поэтому стратегии здесь низкочастотные (таймфрейм 1h и выше), а риск на сделку 1 %.
3. **Акции с таким капиталом не подходят:** рынок закрыт ночью и в выходные, шорт недоступен,
   в США правило PDT требует 25 000 $. Поэтому первая версия работает с криптой.
   Адаптер под акции (Alpaca и др.) можно добавить, интерфейс `Broker` для этого и сделан.
4. **Никому не передавайте приватные ключи кошелька.** Бот работает через API-ключи биржи
   с правами **только на торговлю**, без права вывода, с привязкой к IP вашего сервера.
   Ключи лежат в `.env` на вашем сервере и никуда не отправляются.
5. **Порядок обязателен:** бэктест → walk-forward → paper минимум 2–4 недели → live.
   Если на paper стратегия не зарабатывает, на live она тем более не будет.

## Что внутри

```
tradebot/
├── engine.py            единый торговый цикл для backtest / paper / live (+ внешние сигналы от модуля событий)
├── supervisor.py        три вкладки = три движка с отдельными брокерами и общим хранилищем
├── books.py             описание вкладок (config.yaml) или три вкладки по умолчанию
├── risk.py              размер позиции, дневной лимит убытка, kill switch по просадке
├── backtest.py          event-driven бэктестер + grid search + walk-forward
├── strategies/          ema_trend, donchian (пробой), tsmom (моментум), mean_reversion, ensemble (голосование + фильтр режима)
├── exchange/            paper-брокер, ccxt (крипто), alpaca (США), tinvest (MOEX)
├── intel/               события мира → аналитик (Claude) → идеи → подтверждение → сделка
│   ├── sources.py       GDELT, RSS, NewsAPI, произвольный JSON, входящий webhook
│   ├── universe.py      каталог инструментов по темам (нефть → USO/BNO, медвежий взгляд → SCO)
│   ├── analyst.py       ClaudeAnalyst (структурированный вывод) и RuleAnalyst (без ключа)
│   └── service.py       режимы advise / confirm / auto, лимиты, таймаут идей
├── data/                загрузка истории, replay для бэктестов, синтетика для тестов
├── storage.py           SQLite: сделки, капитал, события, позиции, новости, идеи
├── web/                 панель с вкладками (FastAPI + мобильная страница)
├── notify.py            Telegram: уведомления и команды /status /approve /kill ...
└── __main__.py          CLI: run, backtest, optimize, download, intel, status
```

Ключевое свойство: **один и тот же код** принимает решения в бэктесте, на paper и на live.
Что вы протестировали, то и торгует.

### Защита капитала (риск-менеджер)

| Правило | По умолчанию | Что делает |
|---|---|---|
| Риск на сделку | 1 % капитала | Размер позиции считается от расстояния до стопа |
| Максимум в позиции | 50 % капитала | Не даёт влезть всем депозитом |
| Открытых позиций | 2 | Ограничивает одновременный риск |
| Дневной убыток | 3 % | До конца дня новых входов нет |
| Просадка от пика | 15 % | **Kill switch**: всё закрыть, остановиться, уведомить |
| Без стопа | запрещено | Стратегия без стоп-лосса не получит размер позиции |

Стоп-лосс, тейк-профит и трейлинг отслеживаются движком каждые `TB_POLL_SECONDS`
секунд, а не только на закрытии свечи.

## Быстрый старт

### 1. Локально (Python 3.11+)

```bash
cd tradebot
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r requirements-dev.txt
cp .env.example .env                                     # отредактируйте
python -m pytest -q                                      # 35 тестов должны пройти
```

### 2. Проверка стратегии на истории

```bash
python -m tradebot download --symbol BTC/USDT,ETH/USDT --timeframe 1h --days 730
python -m tradebot backtest --symbol BTC/USDT --days 365
python -m tradebot backtest --symbol BTC/USDT --strategy mean_reversion --trades
python -m tradebot backtest --symbol BTC/USDT --params '{"fast":10,"slow":30,"adx_min":25}'

# подбор параметров + честная проверка на данных, которых подбор не видел
python -m tradebot optimize --symbol BTC/USDT --grid '{"fast":[10,20,30],"slow":[50,100,200]}' --walk-forward 3
```

Смотрите не на `total_return_pct`, а на `sharpe`, `max_drawdown_pct`, `profit_factor`
и `n_trades`. Если в out-of-sample результат разваливается, параметры подогнаны под историю.
Без интернета до биржи есть `--synthetic` (случайные данные, только для проверки, что всё работает).

### 3. Paper trading (виртуальные деньги, живые цены)

В `.env`: `TB_MODE=paper`, `TB_STARTING_CASH=50`, `TB_WEB_TOKEN=<длинная случайная строка>`.

```bash
python -m tradebot run
```

Панель: `http://localhost:8080/?token=ВАШ_TOKEN`. Дайте боту поработать 2–4 недели.

### 4. Live (реальные деньги)

1. На бирже создайте API-ключ: **Enable Spot Trading** (или Futures для шортов),
   **Withdraw — выключено**, IP whitelist — IP вашего сервера.
2. В `.env`: `TB_MODE=live`, `TB_API_KEY`, `TB_API_SECRET` (для OKX ещё `TB_API_PASSWORD`).
3. Положите на счёт 50 USDT. Для шортов: `TB_MARKET_TYPE=swap`, `TB_ALLOW_SHORT=true`,
   `TB_LEVERAGE=1` (плечо выше 2 на мелком счёте — это способ быстро всё потерять).
4. `python -m tradebot run` (или Docker ниже).

## Сервер 24/7 и доступ с телефона

Подойдёт любой VPS за 4–6 $/мес (Hetzner, DigitalOcean, Timeweb) с Docker.

Панель слушает `127.0.0.1:8080`. Чтобы открыть её с телефона, выберите одно из двух:

  `docker-compose.yml` замените `127.0.0.1:8080:8080` на `8080:8080` и открывайте
  `http://<tailscale-ip>:8080/?token=...` из своей частной сети.
- **Caddy / nginx с HTTPS** на домене: проксируйте на `localhost:8080`. Без HTTPS токен
  уйдёт по сети открытым текстом.

### Telegram

1. @BotFather → `/newbot` → токен в `TB_TELEGRAM_TOKEN`.
2. @userinfobot → ваш id в `TB_TELEGRAM_CHAT_ID`. Бот слушается только этого чата.

## Модуль «События и идеи»

1. Каждые `TB_INTEL_INTERVAL_MINUTES` минут бот собирает заголовки из источников
   (GDELT индексирует мировые новости поминутно, бесплатно и без ключа; RSS — BBC, CNBC,
   OilPrice, CoinDesk, Интерфакс и ваши ленты; NewsAPI; любой JSON-эндпоинт).
   Свой инструмент можно и «толкать» в бота: `POST /api/intel/ingest?source=mytool`
   с телом `[{"title": "...", "url": "...", "summary": "...", "ts": ...}]`
   (или `{"items": [...], "fields": {"items": "items", "title": "headline"}}` для другого формата).
2. Новые события уходят аналитику. С ключом Claude это `claude-opus-5-5` со структурированным
   ответом: по каждому событию — инструмент **только из разрешённого списка** вкладки, направление,
   калиброванная уверенность 0–1, горизонт в часах, обоснование, условие отмены идеи и флаг
   «уже в цене». Системный промпт заставляет его быть скупым: большинство заголовков → ничего.
3. Идея становится предложением. Уверенность ниже `TB_INTEL_MIN_CONFIDENCE` или «уже в цене» →
   только в журнал. Режим `advise` → показать и не торговать. `confirm` → сообщение в Telegram
   `/approve 12` или кнопка «Исполнить» в панели. `auto` → уверенность ≥ `TB_INTEL_AUTO_CONFIDENCE`
   исполняется сама, остальное ждёт вас. Неподтверждённые идеи истекают через `TB_INTEL_PROPOSAL_TTL_HOURS`.
4. Исполнение идёт через тот же движок и риск-менеджер: стоп 2 ATR, цель 3 ATR, временной стоп по
   горизонту, размер не больше `TB_INTEL_MAX_POSITION_PCT` капитала вкладки, не больше
   `TB_INTEL_MAX_OPEN` таких позиций одновременно. Шорт во вкладке без права на шорт автоматически
   заменяется обратным ETF, если он есть в каталоге, иначе идея отбрасывается.

Честно о пределах: новости из открытых лент приходят к вам одновременно с миллионами других
участников, и цена часто реагирует за секунды. Модуль силён на событиях с многодневными
последствиями (санкции, ОПЕК, ставки, регуляторные решения) и слаб на «молниях». Поэтому
аналитик обязан помечать «уже в цене», а режим по умолчанию — `confirm`.

Проверить конвейер без торговли: `python -m tradebot intel --all-books`.

## Стратегии

Лучшие практики систематической торговли, которые здесь реализованы: следование тренду и
пробои (основа CTA-фондов), временной моментум (Moskowitz–Ooi–Pedersen 2012), возврат к
среднему в боковике, ансамбль из нескольких сигналов вместо одного, фильтр волатильности,
размер позиции от стопа (постоянный риск на сделку), стопы по ATR и трейлинг, дневной лимит и
kill switch. Чего здесь нет и не будет: «граалей», мартингейла, усреднения убытков, плеча
выше 2 на мелком счёте.

**ensemble** (по умолчанию для акций). Голосование ema_trend + donchian + tsmom, сделка только
при согласии двух из трёх, самый консервативный стоп из согласных, стоит в стороне, когда
20-дневная волатильность выше 2.5× своей медианы.

**donchian.** Пробой 55-дневного максимума/минимума, выход по 20-дневному экстремуму, стоп 2 ATR.
Система «черепах»: редко, но ловит большие движения.

**tsmom** (по умолчанию для ценных бумаг). Знак доходности за 90 дней (пропуская последние 5)
плюс фильтр EMA 100, стоп 3 ATR, трейлинг 4 ATR. Один из самых воспроизводимых эффектов в
финансах: акции, облигации, сырьё, валюты, крипто.

**ema_trend** (по умолчанию для крипто). Вход на пересечении EMA 20/50 при ADX > 20 (есть тренд),
стоп 2 ATR, трейлинг 3 ATR, выход при обратном пересечении. Редкие сделки, большие
движения, подходит для мелких счетов, где комиссия важна.

**mean_reversion.** Покупка ниже нижней полосы Боллинджера при RSI < 30, цель — средняя
линия, стоп 2 ATR, временной стоп 48 свечей, не торгует при ADX > 30. Работает во флэте,
проигрывает в сильном тренде.

Своя стратегия: наследуйте `strategies/base.py::Strategy`, реализуйте `warmup` и
`signal(df, position) -> Signal`, добавьте в `strategies/registry.py`. Стоп обязателен —
иначе риск-менеджер не даст размер позиции.

## Брокеры и вкладки

| Вкладка | Брокер | Paper | Live | Шорт |
|---|---|---|---|---|
| Акции, Ценные бумаги | Alpaca (США) | бумажный счёт Alpaca, реальные цены | реальный счёт | маржа от 2 000 $, иначе обратные ETF |
| Акции MOEX (опция) | Т-Инвестиции | песочница Т-Инвестиций | реальный счёт | через брокера, по умолчанию выключен |
| Криптовалюта | ccxt: Binance, Bybit, OKX, Kraken ... | встроенный paper-брокер на живых ценах | реальный счёт | фьючерсы (`market_type: swap`) |

Вкладки описываются в `config.yaml` (см. `config.example.yaml`). Без файла используются три
вкладки по умолчанию; вкладка без ключей показывается как выключенная с причиной.

## API панели

`GET /api/books` — все вкладки; `GET /api/books/{book}/status|trades|equity|events`;
`POST /api/books/{book}/pause|resume|kill|reset-kill|close/{symbol}`.
`GET /api/intel/status|events|proposals`, `POST /api/intel/run`,
`POST /api/intel/proposals/{id}/approve|reject`, `POST /api/intel/ingest`.
Старые адреса `/api/status` и т. п. работают для первой вкладки.
Токен: заголовок `X-Token`, параметр `?token=` или cookie после первого входа.

## Отказ от ответственности

Программа предоставляется «как есть». Торговля криптовалютой и производными инструментами
может привести к потере всех вложенных средств. Все решения о реальных деньгах принимаете вы.
