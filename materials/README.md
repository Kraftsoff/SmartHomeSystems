# Исходные материалы клиента

Presentation-материалы MiMiSmart, из которых брались факты для сайта. Лежат в
репозитории намеренно: раньше они жили только во вложениях переписки, и часть
из них уже потеряна вместе с той сессией — восстановить их неоткуда.

## Что здесь

| Файл | Объём | Что из него взято |
|---|---|---|
| `Презентация Умный дом MiMiSmart.pdf` | 40 страниц | Основной источник. Датчик протечки заподлицо (стр. 21), статистика по счётчикам, узлы-соседи, очистка воздуха, стабилизация напряжения, два контура молниезащиты, полив по влажности почвы, бассейн с контролем температуры и pH. На стр. 30 — заявление про хранение видео на сервере в другой стране; клиент подтвердил, что формулировка осталась от старой версии продукта, разбор в `audit/06-legal-checklist.md` |
| `Каталог услуг компании MiMiSmart.pdf` | 27 страниц | Состав услуг и направлений |
| `28 сценариев умного дома.pdf` | 16 страниц | Источник доски сценариев на сайте: 28 сценариев с разбивкой по системам |

## Рендеры тура

`рендеры-тура.md` — девять кадров для первого экрана, сделанных 30–31 августа.
Самих файлов здесь нет: хост генератора закрыт сетевой политикой окружения.
В файле записаны адреса и что на каждом кадре.

## Чего здесь нет

Три документа приходили в более ранних сессиях, и их контейнеры уничтожены —
на диске они не сохранились:

- `КП для дизайнеров.pdf`
- `Партнерская программа для агентов 2026.pdf`
- `Партнерская программа для дизайнера 2026.pdf`

Из них по ходу работы был взят один вывод, и он записан в ТЗ: **в трёх документах
стоят три разных процента партнёрского вознаграждения**, и какой действует —
вопрос к клиенту. Сами ставки на сайт не выносятся по прямому указанию клиента.

Отдельно потерян архив `mmsmart ru files.zip` — полные сохранённые страницы
действующего сайта с ассетами. От него уцелело то, что тогда успели положить
в репозиторий: `site-snapshot/` (400 файлов). Из его CSS сняты реальные
дизайн-токены — `tz-site/13`.

## Правило на будущее

Всё, что присылает клиент, кладётся сюда и коммитится в тот же день. Контейнер
сессии эфемерный: то, что не попало в git, исчезает вместе с ним.
